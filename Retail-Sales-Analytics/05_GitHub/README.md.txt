# Retail Sales Analytics

## Project Overview

Retail Sales Analytics is an end-to-end Power BI project developed to analyze retail sales, profitability, customer behavior, and product performance.

## Objective

The objective of this project is to analyze retail sales data and generate meaningful business insights using interactive Power BI dashboards.

## Tools Used

- Microsoft Excel
- Power BI
- Power Query
- DAX

## Dashboards

- Executive Dashboard
- Sales Dashboard
- Profit Dashboard
- Customer Dashboard
- Product Dashboard
- Executive Summary

## Key Analysis

- Sales Performance
- Profitability Analysis
- Customer Analysis
- Product Analysis
- Regional Performance
- Monthly Sales Trends
- Loss-Making Products
- Top Performing Products

## Power BI Features

- KPI Cards
- DAX Measures
- Slicers
- Drill-through
- Tooltips
- Conditional Formatting
- Page Navigation
- Interactive Visualizations

## Business Questions

- Which region generates the highest sales?
- Which category generates the highest profit?
- Which products are loss-making?
- Which customers contribute the most sales?
- How does sales performance change over time?
